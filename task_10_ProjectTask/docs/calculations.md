# Расчёты

## Исходные сущности

- `users` - пользователи
- `categories` - категории заявок
- `support_staff` - сотрудники поддержки
- `tickets` - заявки с JSON-комментариями

## Поля времени

В `tickets.csv` используются:

- `created_at` - время создания заявки
- `updated_at` - последнее обновление заявки
- `resolved_at` - время решения или закрытия заявки

Для статусов `новая` и `в работе` поле `resolved_at` пустое.

## tickets_resolved

Количество заявок сотрудника со статусом:

- `решена`
- `закрыта`

## avg_resolution_time_hours

Среднее значение:

```text
resolved_at - created_at
```

в часах только для финальных статусов.

## backlog

Количество заявок сотрудника со статусом:

- `новая`
- `в работе`

## avg_resolution_time

Среднее время решения по паре:

- категория
- приоритет

## total_tickets

Количество заявок по паре:

- категория
- приоритет
